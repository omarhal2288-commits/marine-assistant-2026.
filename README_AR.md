# مساعد مارين الذكي — مشروع Android

هذه حزمة مصدر مستقلة عن مشروع BrightBean. لا تحتوي على APK جاهز؛ يلزم بناء APK أولاً.

## الوظائف الموجودة في هذا الإصدار
- فتح WhatsApp Business وInstagram وSnapchat وTikTok وFacebook وChatGPT إذا كانت مثبتة.
- شاشة إعدادات لتفعيل خدمة Android Accessibility.
- قراءة النصوص التي يتيحها التطبيق المفتوح لخدمة الوصول.
- الرجوع والرئيسية.
- محاولة الكتابة في الحقل المحدد والنقر على عنصر حسب النص، مع نافذة تأكيد قبل التنفيذ.

## حدود مهمة
- لا يوجد تحكم كامل أو مضمون في كل تطبيق؛ بعض التطبيقات تحجب عناصرها عن خدمات الوصول أو تغيّر واجهاتها.
- لا يتجاوز كلمات المرور أو التحقق أو الحماية.
- لا يرسل رسائل أو ينفذ مدفوعات تلقائياً.
- يجب تفعيل خدمة الوصول يدوياً من إعدادات Android، ويمكن إيقافها في أي وقت.
- اختبر على حساباتك وبإشرافك. لا تستخدمه لإرسال أو حذف شيء دون مراجعة.

## البناء عبر GitHub Actions من الهاتف
1. أنشئ مستودع GitHub جديداً باسم MarineAssistant (مستقل عن brightbean-studio).
2. ارفع محتويات هذا المجلد إلى المستودع الجديد.
3. افتح تبويب Actions، ووافق على تشغيل Actions إذا طلب ذلك.
4. شغّل workflow باسم Build Marine Assistant APK.
5. بعد نجاحه نزّل artifact باسم marine-assistant-debug-apk؛ بداخله app-debug.apk.

## متطلبات البناء
- JDK 17
- Gradle 8.9
- Android SDK Platform 35
- Android Build Tools المناسبة

هذا المشروع يستخدم Android Gradle Plugin 8.7.3 وKotlin 2.0.21.
